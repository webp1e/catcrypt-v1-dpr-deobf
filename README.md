# catcrypt-v1-dpr-deobf
Скрипт для дешифровки dpr файлов что были обфусцированны catcrypt v1

Дешифровка одного файла:
```
python3 decr.py path/to/file.pdr
```
Дешифровка нескольких файлов:
```
python3 decr.py file.pdr file.pdr file.pdr
```
Для дешифровки с сохранением зашифрованного pdr файла применяется параметр --keep
```
python3 decr.py --keep file.pdr
```
Для дешифровки всей директории
```
python3 decr.py --dir /path/to/dir/
```


# Логика шифрации
Сама логика шифрации состоит всего из 2 компонентов
- 1 компонент - каждые 4 байта идут 4 байта из статичного xor ключа
- 2 компонент - сдвиг по константе +105


использовать искключительно в познавательных целях
